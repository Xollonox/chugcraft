# Moonlit Cottage showcase

Start ChugCraft 3.2, open Singleplayer and choose Import World. Select Moonlit-Cottage.chugcraft.json from this folder. It creates a separate Creative world with building materials, a cottage, connected tinted windows, gates, a mosaic path, lanterns, a waterfall fountain and a contained lava pool.

Use `/time midnight` to try brighter nights. Options → Video → Night visibility defaults to 75%; choose 100% for the brightest nights or 0% for the original darkness. Use `/time day` to return to daylight.

This is a synthetic test/showcase world, not a survival playthrough. The fountain's source is suspended so its downhill flow is easy to see. Back up your own worlds before updating; never open a 3.2 world in older releases.
